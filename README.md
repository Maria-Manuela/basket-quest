# Basket Quest

Interactive shopping-basket planner. Pick a challenge, build a basket within budget and tags, get live recommendations, and check out with MobilePay.

## Features

- Challenge picker with live scoring and progress
- Product catalogue with categories and tags
- Basket with quantity controls and free parcel-shop delivery threshold
- Recommendations based on your current basket
- Checkout with delivery options and MobilePay
- About and Contact pages
- Cart and best score saved in the browser (`localStorage`)

## Run locally

No build step required — the app is a single `index.html` file.

```bash
npm start
```

Then open [http://localhost:5173](http://localhost:5173).

Or open `index.html` directly in your browser.

## Stack

- HTML
- Vanilla JavaScript
- Tailwind CSS (CDN)
